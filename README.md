# csh-ddos
DDoS-csh
```bash
# Update packages
pkg update && pkg upgrade

# Install Python and required dependencies
pkg install python
pkg install openssl
pkg install clang  # For better performance

# Install pip packages
pip install aiohttp requests

# If you encounter SSL issues:
pkg install openssl-tool
```

install
```bash
git clone https://github.com/drkrovav/csh-ddos.git


```

```bash
cd csh-ddos
```
```bash
pip install -r requirements.txt
```

```bash
python csh-ddos.py
```
